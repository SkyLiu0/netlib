# NETLIB
NETLIB LP dataset in `.mps` format, containing 114 feasible and 29 infeasible instances.

For the feasible instances, optimal objective values and problems presolved by Gurobi 14.0.0 (automatic presolve, four threads, feasibility and optimality tolerances of 1e-8) are also provided. The CSV records solve time in seconds and objective value for each original feasible model.

For the original collection, please visit [https://www.netlib.org/lp/](https://www.netlib.org/lp/).
